# Hardware

PCB and enclosure design files for the esp32-qiyang smart scale.

- `pcb_Crimp-ER.kicad_{pro,sch,pcb}` — KiCad project (schematic + layout).
- `fab/` — gerbers, drill files, pick-and-place, fabrication zip.
- `crimp-ER covers/` — 3D-printed enclosure (`*.stl` + `*.step`).
- `renders/` — PNG/JPEG previews.
